## Performance testing · Locust

The application was tested locally with **150 concurrent users** (ramp-up: **3 users/s**). During the sustained phase, throughput reached approximately **80–100 requests/s**. The recorded endpoint sample included **67,039 requests**, with **121 failures (0.18%)**.
